# Changelog

## 0.1.0

- First release.
- Providers: Stripe, GitHub, Shopify, Razorpay, Slack, Paddle, Lemon Squeezy, Square, Twilio, Standard Webhooks, Svix, Clerk, Resend and custom HMAC schemes.
- `verify`, `verifyOrThrow`, `verifyRequest` (Fetch API) and `hooksealExpress` middleware.
- `sign` helper for tests.
- Replay protection, key rotation, constant-time comparison.
- CLI: `hookseal sign`, `hookseal verify`, `hookseal providers`.
